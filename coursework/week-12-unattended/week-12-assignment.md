## Learning Outcomes Addressed

After completing this assignment, you should be able to:

- Understand Backend Web Development Concepts
- Develop and Implement Web Applications Using Express.js and Flask
- Work with Databases for Dynamic Content Management
- Manage Static Assets and User Sessions

## Task

Reflect and respond to the following questions.

In this assignment, you will implement a server-side rendering web application using both Express.js with the Pug template engine and Flask with the Jinja2 template engine. You will also learn how to interact with a database, manage dynamic content, and render content with template engines.

### 1. Express.js with Pug Template Engine (5 Marks)

a) Set up an Express.js web application with Pug template engine.

b) Implement dynamic content rendering using Pug

c) Database integration using SQLite in Express.js

### 2. Flask with Jinja2 Template Engine (5 Marks)

a) Set up a Flask web application with Jinja2

b) Dynamic content rendering with Jinja2

c) Handle different HTTP methods in Flask

### 3. Static Assets and Session Management (5 Marks)

a) Serve static assets in Express.js

b) Manage session state using Express.js sessions

c) Serve static assets in Flask

d) Manage session state using Flask sessions

### 4. Database interaction and CRUD operations (5 Marks)

a) Set up a Flask application to perform CRUD operations with SQLite.

b) Set up CRUD operations in Express.js using SQLite.
