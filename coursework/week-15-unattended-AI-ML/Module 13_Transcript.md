## Video 6: What are the Types of ML Algorithms?

What are the types of ML algorithms? In this video, we have explored the three major types of machine learning algorithms, Supervised Learning, Unsupervised Learning, and Reinforcement Learning. Each type offers unique approaches and insights for developing intelligence systems.

Supervised learning, a foundational method in machine learning. Supervised learning involves training a model on a dataset that includes both input data and the corresponding labelled outputs.

The model's task is to learn underlying patterns in the data, to map inputs to their correct output. The ML algorithm is provided with a large input datasets respective of output or event or class. Usually prepared in consultation with a subject matter expert of a respective domain. There are two types of supervised learning. One is regression, so here the model predicts a continuous output based on the input. For example, predicting housing prices from features like location, size, and number of rooms. The output is a numerical value directly related to the inputs. The next one is classification. This involves categorising input data into predefined classes. For instance, determining whether an email is a spam or not a spam is a classification problem. The output here is a class label. Building a Supervised model involves three key steps. Training the model learns from a historical dataset, understanding the patterns and associated with each output. The second step is the testing or validation. The model's accuracy is evaluated using a new set of data which are not seen during the training phase. The last step is Prediction. Finally, the trained model is applied to new data to make predictions that inform decisions. By learning from the past data, supervised learning models can predict future events or classify new examples, making it a powerful tool for a wide range of applications.

Unsupervised learning. Unsupervised learning is a type of machine learning that focuses on identifying patterns in data without need for labelling it. Unlike supervised learning, unsupervised learning does not use labels as part of third training. That is, it works on unlabelled data. Instead, it analyses the data to find natural groupings or structures within it. Also, manually labelling huge data is a very expensive process. The key applications of unsupervised learning include, clustering This is used to group similar customer profiles, which can help in market segmentation and target marketing. The second application is Dimensionality reduction technique. This technique like PCA, which is called Principal Component Analysis, are used to reduce the number of variables under consideration, helping to simplify models without losing important information. Third application is Anomaly Detection. This is crucial in identifying unusual patterns that could indicate fraudulent credit card transactions or other security breaches.

The goal of unsupervised learning is to model the underlying structure or distribution in data to learn more about the data itself. It's particularly useful in exploratory data analysis or when the data lacks label.

The third type of machine learning is reinforcement learning. Reinforcement learning is a type of machine learning where algorithm learns to make a sequence of decisions by interacting with an environment to achieve a goal. The unique aspect of reinforcement learning is its focus on finding actions that yield the maximum reward, rather than just correct mapping. Some of the key features include Action-reward relationship. For every action taken by the algorithm, there's a reward defined by the system. The algorithm's goal is to maximise these reward over time, which guides its learning process. Learning through trial and error. The algorithm learns by repeatedly trying different strategies and improving them based on the rewards received.

Some of the examples include gaming, where the algorithm learns, gaming strategies that maximise the points won during the game. The next is self-driving Cars, where the Algorithms learn to make driving decisions that lead to reach a destination safely and efficiently.

In reinforcement learning, the model isn't provided with correct answer, but instead must discover it through continuous feedback from its action. This is analogous to teaching a robot to navigate in a maze, where it must try various routes and learn from success and failures to find the most efficient path to the goal.

There are three fundamental tasks of machine learning apart from three types of machine learning. There are three fundamental tasks of machine learning, which are classification, regression, and clustering. Each of these tasks include different techniques and algorithms to process and analyse data, providing us the means to solve complex problems across various fields.

First one is classification. The classification tasks divide data into categories based on learned patterns from previous data. The objective is to accurately assign new data points to one of these categories. A common example in identifying whether an email is a spam or not a spam based on its content. So this is an example for classification. The second task is called regression. This task involving predicting a continuous outcome based on one or more variables. The goal is to find the line of best fit that can model the relationship between the inputs and the continuous output. For example, predicting the price of a house based on its features like size and location. So this is an example for regression. The third task is called clustering. Unlike classification clustering groups data points into different clusters based on similarity, but without pre-labelled categories. This is used, for examples, in market segmentation to group customers with similar behaviours without prior knowledge of the group.

Each of these tasks plays a crucial role in how we interpret and utilise data, not only on that, but also making machine learning an invaluable tool in today's data driven world.
