## Video 5: Introduction to Pandas Series

In the previous videos of this module, we have discussed at length about the NumPy ndarray data structure. The ndarray data structure offers significant improvement in terms of capability and performance relative to the Python built-in basic data structures. However, the ndarray data structures also has its own limitations. First ndarray is a homogeneous data structure and all items must be of the same data type. This is not reflective of real-world datasets, which are typically mixed type. Second, items stored in an ndarray can only be referenced using zero-based index numbers. As the number of columns, or variables, and rows in a dataset increases, it becomes increasingly challenging to reference data using zero-based index numbers. Ideally, we want to be able to use text label to reference the variables and rows instead.

For example, instead of referencing our dataset as variable 30 or record 1,000, we will prefer to use variable "age" and record associated with a particular alphanumeric student number. The Pandas Library provides two new data structures to address these limitations of ndarray, namely Series and DataFrame. In this video, we will begin by examining the Pandas Series data structure first. Series is a one-dimensional data structure. In the next video, we will then look at how multiple Series data structures can be combined to create a two-dimensional DataFrame. The Pandas DataFrame is the primary data structure that is used for data preparation as well as the subsequent data analysis and machine learning modelling. Pandas Series is essentially similar to a Python list but with some additional features.

More specifically, the internal structure of a Series data structure consists of two lists that are associated with each other. The main list holds the data, which can be any NumPy type. Each piece of data or element is associated with a label. The label is contained within the other index list. As shown in this diagram, by default, the label is a zero-based index number. But in this case, the zero-based index number can be overridden with a more meaningful text label. A Series can be created by calling the Series() constructor and passing in a Python list containing the values to be included in the Series. To override the default zero-based index number with a more meaningful text label, the index option can be used to pass in a list of strings. Observe the difference between the label list of the two Series data structures. Note that all values in a Series must be homogenous, that is, of the same data type.

Internal elements in a Series can be selected using the square brackets notation with either a zero-based index number or a text label, if one is defined with the index option. When using a zero-based index number, you should use the iloc property. Series thus provides a good degree of flexibility in indexing elements. Observe that multiple values can be selected and that values can also be assigned to elements with both a zero-based index number and text label. We can perform various operations and mathematical functions that are applicable to NumPy ndarray to Pandas Series too. Beyond these basic operations, we can also evaluate its values within a series to provide information on the unique values, count of duplicate values and whether a value is present or not. This information is useful for descriptive analytics.

For example, if a string variable contains too many unique values, it should not be considered as a structured categorical variable but rather unstructured text. Observe that Series and dict are actually very similar in the general structure. Thus, Series can be created from a dict object. ## Video 6: Introduction to Pandas DataFrame

A Pandas DataFrame is essentially a two-dimensional data structure resembling a database table and spreadsheet. DataFrame extends the series to multiple dimensions or columns. It is essentially a collection of columns, each of which can contain values of different data types. Thus, DataFrame can represent and store a real-world mixed-type dataset. Recall that a series has an index list containing labels associated with each element.

A DataFrame has two index lists. The first index list is associated with the rows and serves a similar function as the index list in a Series. But in this case, each label is associated with multiple values in that row. Think of this as the row header in a spreadsheet or primary key in a relational database table. The second index list contains a collection of labels, each associated with a particular column or variable. Think of this as the column header in a spreadsheet or column or attribute name in a relational database table.

In this example, the DataFrame contains three columns, namely color, object and price. Observe that price is a floating-point number whereas color and object are string. Each label or zero-based index number on the row header is associated with all three values of colour, object and price for a particular row. Another way to look at a DataFrame is to think of it as a dict of Series. The keys of the dict are the column names. The values are the Series. Furthermore, all elements of each series are mapped according to a list of labels called the index. The most common way to define a DataFrame is to pass a dict object to the DataFrame() constructor. The dict object contains a key for each column to be defined together with a list of values. This approach is quite similar to how we define a Series but now we are essentially defining multiple Series objects to make up the DataFrame.

Let's move on to find out how to select elements in a DataFrame. To select the contents of a column, we can use the column name as an index or use the column name as an attribute of the DataFrame. To select the content of a row, we can use the iloc attribute with a positional index or the loc attribute with the required label index. To select the content of a cell, we combine the iloc or loc attribute with the required column name. We can assign new value to each cell with the assignment operator and the loc attribute of the DataFrame. Arithmetic operations can be performed between two DataFrame objects using the built-in arithmetic methods such as add(), sub(), div() and mul(). In this example, observe that the resulting DataFrame contains the 'NaN' special values. This means that there are missing values in the dataset. For two elements to be added, their column index and row index must exist across both DataFrame objects. Statistics function can also be applied on a DataFrame.

In this example, the DataFrame describe() function can generate the five-number summary descriptive statistics for each of the numerical variables. Observe that Pandas DataFrame addresses all the limitations associated with Python built-in basic data structure and the NumPy ndarray object. With DataFrame, we can store and manipulate a two-dimensional, labelled, mixed type dataset effectively with minimal effort. ## Video 8: Introduction to Matplotlib

In this video, you will learn how to use the matplotlib library to create two-dimensional charts for data visualisation using data stored in a Pandas DataFrame. Let's begin with an overview of the matplotlib architecture. Matplotlib provides a set of functions and tools that allow the representation and manipulation of a figure, which is the main object, and its associated internal objects. Other than graphics, Matplotlib also handles events and graphics animation. Thus, Matplotlib can produce interactive charts that can respond to events triggered by keyboard or mouse movement. The architecture of Matplotlib is structured into three layers with unidirectional communication. Each layer can only communicate with the underlying layer. At the lowest level, the backend layer consists of the Matplotlib application programming interface and a set of classes that are used to represent the graphic elements.

The artist layer is an intermediate layer representing all the elements that make up a chart, For example, title, axis, labels, markers, etc.

The scripting layer consists of the Pyplot interface for actual data calculation, analysis and visualisation. Putting all three layers together, the scripting layer is used by the data analyst to create the required objects constituting the chart, which are represented in the artist layer that forms the basis for the backend layer to render the actual chart. At the artist layer, the three main objects in its hierarchy include the figure, Axes, and Axis. Each figure can consist of one or more Axes, with each Axes forming one plot or subplot. Each instance of a chart corresponds to an instance of artist structured in a hierarchy. As shown in this diagram, an axes consists of an x-axis and y-axis, together with the actual plotting element, in this case, a two-dimensional line plot. Each Axis is further broken down into its label and ticks. This hierarchical structure allows every internal object to be scripted and customised to the exact requirements of the data analyst. The Pyplot module is a collection of command-style functions that allow the data analyst to operate or make changes to the figure. For example, to create a new figure.

A simple chart can be created using the Pyplot object's plot() function. The plot() function uses a default configuration that does not have title, axis label, legend, etc. Observe that the list of integer values passed into the plot() function appears on the y-axis. The x-axis corresponds to the zero-based index number of the elements in the list. The default configuration can be changed to obtain the desired chart. In this example, the line plot has been replaced by a red colour dot plot with a proper chart title. The scaling of the x-axis and y-axis can also be customised. Observe that there are two lists of integer values being passed into the plot() function. The first list appears on the x-axis and the second list appears on the y-axis.

Matplotlib is tightly integrated with Pandas. To create a simple line plot from data in a Pandas DataFrame, we can use the DataFrame.plot() function, which relies on matplotlib. By default, you will get a line plot. To customise the line plot created by the DataFrame.plot() function, you will need to use the matplotlib directly. Observe the creation of an annotation on the chart itself. To create a bar plot, you need to set the kind. By default, the index of the DataFrame is a zero-based number and thus the x-axis are the numbers 0 to 4. You can change the index of the DataFrame to the Name column and replot the bar plot. Observe that the chart with name as the x-axis is certainly more informative. By now, you will have noticed that creating two-dimensional charts in Python using matplotlib is very easy given the integration with Pandas.

## Video 9: Data Visualisation and Matplotlib

In data analytics and machine learning modelling, exploratory data analysis or EDA is an important step that helps you to understand more about the nature of relationships among variables in the dataset. Through the EDA process, you will be able to identify the most suitable independent variables for predicting the phenomenon of interest, that is the dependent variable, and to find the most appropriate model to fit the data. This video introduces you to the use of the Matplotlib library to create more advanced data visualisation for EDA. Let's begin with the boxplot. The boxplot is a visual summary of the descriptive statistical properties of a variable. In particular, it can be used to depict the quartiles of numerical data. In a boxplot, the box extends from the first quarter to the third quartile values of the data, with a line at the median or the second quartile. The whiskers extend from the edges of the box to show the full range of the data. The position of the whiskers can represent different information. If there is no outlier, the whiskers show the minimum and maximum values of the data.

If there are outliers, the whiskers show the lowest and highest datum that they are still within 1.5 times the interquartile range of the lower and upper quartile, respectively. Any observations that are past the end of the whiskers are considered as outliers.
