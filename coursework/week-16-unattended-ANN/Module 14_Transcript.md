Back propagation. Back propagation is a cornerstone learning algorithm in neural networks, crucial for refining predictions during training. Feedforward propagation, each input from the training data passes through the network layer by layer until an output is produced. In other words, back propagation, adjust the weights in the neural network by calculating and minimising the error from the output back to the input using gradient descent.
