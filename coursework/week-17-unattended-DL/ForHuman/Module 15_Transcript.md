In this segment, we will explore recurrent neural networks, or simply called as RNNs, which are pivotal framework in deep learning for natural language processing. RNNs are also similar to CNNs for computer vision but tailored for sequential data processing such as language or time series analysis. RNNs are renowned for their capability in document classification, text generation and many more. Their unique feature is the ability to process sequences. If given a series of words, an RNN can predict the subsequent word. This predictive ability stems from networks design, where the output from each step is fed back into the network as part of the input for the next step. The diagram here illustrates an unrolled, RNN. Each node labelled A represents a batch of neurons, processing input at different timesteps. The input at each time step, which is xt, is processed to produce an output which is ht, which then becomes part of the input for the next time step. This sequential processing allows the network to maintain a memory over time, leveraging previous computations, ht-1, ht-2, and so on as inputs along the current input xt. By effectively capturing information from the entire sequence up to that point.

As you can see, the output from each neuron that is ht is recycled back into the network, providing a memory effect that allows the network to make informed predictions based on previous data. Unlike Feedforward networks where data flows in one direction. The RNN feedback loop enables it to remember previous inputs. This memory is crucial when the context or sequence of events influence the outcome.

Visualise the RNN as a multiple copies of the same network, each passing information to the next. This structure allows the network to handle variable length input sequence essential for tasks like language translation or speech recognition where the context from earlier in the sequence affects the understanding of predictions with later on.

Recurrent neural networks excel in handling tasks where the prediction depend on short-term context within the data. The figure illustrates an unrolled RNN, showing how it process sequential data over time. Each node labelled A represents the network at a specific timestep processing one input from the sequence and passing its output to the next step. This process begins at time t0 with the initial x0 and the corresponding hidden state h0, which is then passed as an input to the next node.

This pattern continues with each node receiving an input X and the hidden state from the previous node h until time t n where N is the final time step in the sequence. For instance, in the text example, the colour of the sky is the RNN receives each word one at a time. 'The' at time t0, colour at t1, 'of' at t2, "the" at t3, 'sky' at t4 and finally is at t5. The network must remember relevant information from all previous words to accurately predict the word blue as the next word. Each word influences this hidden state, which carries forward this memory to the sequence context enabling the prediction of next word based on short term dependencies. This process underscores the RNN capability to manage the sequence where the relationship between the item is closely linked over short spans. However, RNN struggles with long-term dependencies, which is a limitation crucial when the context needs for a correct prediction that spans a large gap in the input sequence.

In the example, I have spent 20 years teaching computer science for the underprivileged kids in France. Then we have 20 to 40 words, and then I have the sentence, I can speak fluent, and you need to predict the next word. The answer, which is "French" heavily relies on the word France mentioned much earlier in the text. Traditional RNNs tend to forget such distant information, failing to recall "France" when predicting the language spoken. This limitation stems from the vanishing gradient problem where the influence of information decreases as it travels through each step of the network, making it hard for standard RNNs to maintain long-term dependencies. As a result, while RNNs are powerful for many sequential tasks, their application is limited by the length of dependencies they can effectively remember and utilise for predictions.

To overcome these limitations of RNN people came up with a new deep learning architecture called LSTM Architecture or long short-term memory network. The core purpose of LSTM is to extend the memory of data sequence significantly longer than RNNs can handle, allowing for more extended dependency recognition in sequence data. LSTM achieves this through specialised memory blocks connected into layers each consists of three distinct gates. Input gate, forget gate and output gate each playing a vital role in memory management. The forget gate is crucial as it filters out the unnecessary information from previous step, ensuring only relevant data persists. The input gate decides which of the current input data should be stored in the LSTMs memory state, ensuring that significant new information is retained for future steps. The output gate, which determines what the next output should be based on both the new input and the information already stored in the memory cell. These gates collectively enable the LSTM to retain information over a long period and handle long-term dependencies more effectively than traditional RNNs. This makes LSTM particularly suited for complex tasks like language translation, speech recognition and time series prediction where understanding extended context is important.
